# Proposals — drafted by the agent, not yet confirmed

Facts the agent believes but nobody has approved. They are allowed to work:
they may steer sampling, group files, and appear in a *proposed* folder name
(carrying a `draft:` prefix in the plan CSV, so a plan review shows which
names rest on unconfirmed memory).

They may **not** become a Visual Sorting exemplar, and may not be written into
`photo-entities.json` as confirmed. Re-observing a draft in a later batch does
not confirm it — it raises `obs_count` and re-tags it `ai-reinforced`.

Promotion happens only at a memory checkpoint, via the review table.
A rejected draft is never proposed again.
